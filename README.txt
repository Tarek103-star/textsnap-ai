TextSnap AI — نموذج أولي
=========================

الميزات:
- استخراج النص من الصور داخل المتصفح بواسطة Tesseract.js.
- لغات OCR: العربية (ara)، الفرنسية (fra)، الإنجليزية (eng) ومجموعاتها.
- تعديل النص ونسخه وتنزيله TXT.
- حفظ النص كـ PDF عبر نافذة الطباعة في المتصفح.
- ترجمة عبر نقطة نهاية متوافقة مع LibreTranslate قابلة للتغيير.
- ملفات PWA أولية للتثبيت على الهاتف بعد النشر عبر HTTPS.

التشغيل:
1. فك ضغط الملف.
2. افتح index.html في متصفح حديث مع اتصال بالإنترنت. الأفضل استخدام خادم محلي أو نشره عبر HTTPS.
3. اختر صورة، اختر اللغات، ثم اضغط استخراج النص.
4. للترجمة، استخدم خدمة LibreTranslate تملكها أو لديك إذن باستعمالها. الخدمة العامة قد تتطلب مفتاحًا أو تمنع طلبات المتصفح بسبب CORS.

النشر المجاني:
- ارفع الملفات إلى مستودع GitHub عام.
- فعّل GitHub Pages من إعدادات المستودع.
- افتح الرابط المنشور عبر HTTPS ثم اختر "إضافة إلى الشاشة الرئيسية" على الهاتف.

ملاحظات:
- هذه نسخة أولية وليست تطبيقًا تجاريًا مكتملًا.
- Tesseract.js وموديلات اللغة تُحمّل من CDN عند الحاجة، لذا يلزم الإنترنت أول مرة.
- OCR العربي قد يحتاج إلى مراجعة يدوية، خصوصًا مع الصور المائلة أو منخفضة الدقة.
- لا تضع مفاتيح API سرية داخل الواجهة العامة؛ استخدم خادمًا خلفيًا إذا احتجت مفتاحًا.
- ملف PDF يُنشأ عبر وظيفة الطباعة في المتصفح؛ اختر "حفظ كملف PDF".
