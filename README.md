# TextSnap AI — إصدار تجريبي v4

## محتويات الحزمة
- `index.html`: واجهة التطبيق، استخراج النص OCR، الترجمة، النسخ والتنزيل والطباعة إلى PDF.
- `sw.js`: عامل الخدمة مع تحديث إصدار الذاكرة المؤقتة حتى لا تبقى الواجهة القديمة.
- `manifest.webmanifest`: إعدادات تثبيت التطبيق كتطبيق ويب تقدمي.
- `icon.svg`: أيقونة التطبيق المستخدمة في الواجهة والـ manifest.

## النشر على GitHub Pages
1. افتح مستودع `textsnap-ai` على GitHub.
2. ارفع الملفات الأربعة إلى جذر الفرع `main`، بجانب بعضها تمامًا.
3. عند السؤال عن الاستبدال، وافق على استبدال الملفات ذات الأسماء نفسها.
4. احفظ التغييرات عبر **Commit changes**.
5. انتظر اكتمال نشر GitHub Pages، ثم افتح:
   `https://tarek103-star.github.io/textsnap-ai/?v=4`

## الوظائف
- استخراج النص من الصور بواسطة Tesseract.js.
- لغات OCR المضمنة في القائمة: العربية والإنجليزية والفرنسية والإسبانية والألمانية والإيطالية والبرتغالية والتركية، مع دعم اختيار لغتين معًا لبعض التركيبات.
- تحرير النص ونسخه وتنزيله بصيغة TXT.
- طباعة النص وحفظه PDF من نافذة الطباعة في المتصفح.
- ترجمة عبر واجهة MyMemory العامة.

## ملاحظات مهمة
- يتطلب OCR تحميل مكتبة Tesseract وبيانات اللغة من الإنترنت عند الاستخدام الأول.
- خدمة MyMemory عامة ومجانية بحدود استخدام وتوفر غير مضمون. لذلك قد تتوقف الترجمة أو ترفض النصوص الطويلة. لا تضع بيانات سرية في هذه الخدمة.
- لا يحتوي هذا الإصدار على خادم خلفي أو مفتاح API خاص. للحصول على ترجمة مستقرة تجاريًا، اربط لاحقًا مزود ترجمة موثوقًا من خلال خادم خلفي يحمي مفتاح API.
- ملف `sw.js` يستخدم `textsnap-ai-v4` كاسم ذاكرة مؤقتة جديد، ويجلب صفحة HTML من الشبكة أولًا لتقليل مشكلة ظهور النسخة القديمة.
- أيقونة SVG مناسبة للمتصفحات الحديثة؛ يمكن إضافة أيقونات PNG بأحجام 192 و512 بكسل لاحقًا لتحسين دعم التثبيت على بعض الأجهزة.

## اختبار سريع
1. افتح التطبيق على اتصال إنترنت.
2. اختر صورة إنجليزية واضحة، واجعل لغة OCR هي الإنجليزية، ثم اضغط «استخراج النص».
3. اضغط «نص تجريبي»، واختر العربية، ثم اضغط «ترجمة النص».
4. جرّب النسخ والتنزيل والطباعة PDF.
